## pixel-lace-dream-01.png (700×1150)

淡蓝到白的竖版海报:上半是人像照片,下半是白底,中段淡出。

**做法拆解**
1. **底色**:周期性蓝色 → 白色的纵向渐变,上半保留照片,约 50% 处开始淡入纯白(渐隐带很宽,没有硬边)。
2. **像素旋涡遮罩**:一条由像素块拼成的卷草(5 个旋涡,左右交替,S 形连接),格子约 14 px。同一个遮罩用了两次,方向相反:
   - 上半:遮罩内是**纯白**,盖在照片上,照片从遮罩外面露出来;
   - 下半:遮罩内是**照片**(蓝、粉、肤色),遮罩外是白底。
   即上半是"白色花纹压在图上",下半是"图从白色里透出花纹",正好互为反相,中段交接。
3. **逐格透明**:遮罩里的格子不是全白,少数格子半透明或全透,透出下面像素化的照片颜色,所以边缘有蓝、粉的碎格。
4. **点阵蕾丝**:左右边缘有小点组成的花边纹样(同一类旋涡轮廓,但用细点而不是实块),颜色是淡蓝灰。
5. **星光**:零散的金色小星星(上半)和蓝色十字/菱形小闪光(下半)。
6. **质感**:整张叠了胶片颗粒和细密的半调网点,照片本身偏柔焦、调成冷粉蓝。

**对应的效果**
| 需要 | 现有效果 | 新做 |
|---|---|---|
| 胶片颗粒 | `effects/grain` | |
| 半调网点质感 | `effects/halftone`、`effects/dither` | |
| 冷蓝调色 | `effects/duotone`(改 tableValues) | |
| 像素旋涡遮罩,上白下图反相 | | `effects/pixel-ornament` |
| 渐隐到白 | | 渐变遮罩(并入 pixel-ornament) |
| 点阵蕾丝 | | `.px-lace`(并入 pixel-ornament) |
| 星光闪点 | | `effects/sparkle` |
