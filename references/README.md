## pixel-lace-dream-01.png (700×1150)

淡蓝到白的竖版海报:上半是人像照片,下半是白底,中段淡出。

**做法拆解**
1. **底色**:周期性蓝色 → 白色的纵向渐变,上半保留照片,约 50% 处开始淡入纯白(渐隐带很宽,没有硬边)。
2. **像素旋涡遮罩**:一条由像素块拼成的卷草(5 个旋涡,左右交替,S 形连接),格子约 14 px。同一个遮罩用了两次,方向相反:
   - 上半:遮罩内是**纯白**,盖在照片上,照片从遮罩外面露出来;
   - 下半:遮罩内是**照片**(蓝、粉、肤色),遮罩外是白底。
   即上半是"白色花纹压在图上",下半是"图从白色里透出花纹",正好互为反相,中段交接。
3. **逐格透明**:遮罩里的格子不是全白,少数格子半透明或全透,透出下面像素化的照片颜色,所以边缘有蓝、粉的碎格。
4. **点阵蕾丝**:左右边缘有小点组成的花边纹样(同一类旋涡轮廓,但用细点而不是实块),颜色是淡蓝灰。
5. **星光**:零散的金色小星星(上半)和蓝色十字/菱形小闪光(下半)。
6. **质感**:整张叠了胶片颗粒和细密的半调网点,照片本身偏柔焦、调成冷粉蓝。

**对应的效果**
| 需要 | 现有效果 | 新做 |
|---|---|---|
| 胶片颗粒 | `effects/grain` | |
| 半调网点质感 | `effects/halftone`、`effects/dither` | |
| 冷蓝调色 | `effects/duotone`(改 tableValues) | |
| 像素旋涡遮罩,上白下图反相 | | `effects/pixel-ornament` |
| 渐隐到白 | | 渐变遮罩(并入 pixel-ornament) |
| 点阵蕾丝 | | `.px-lace`(并入 pixel-ornament) |
| 星光闪点 | | `effects/sparkle` |

## pixel-lace-dream-02 ~ 06(网图,仅作学习参考,不商用;04、05 已嵌入练习稿,仓库建议保持私有)

同一种情绪的不同侧面,用来给 `dusk-lace` 风格和 "Girlhood Heroism" 定调:
- **02** 纽约黄昏:灰紫到粉的天空,楼顶暖金色灯光。→ 配色(`--sky1..3`)和城市剪影。
- **03** 气球与肥皂泡,远处铁塔剪影:灰粉气球,透明泡泡带高光。→ `.balloon`、`.bub`。
- **04** 黑底白色舞者油画:人像发白发光,发丝像丝线。→ 第 3 页的"白色柔光 + 深紫底"。
- **05** 奶白色镂空骨骼雕塑:柔和的布面阴影。→ 细线、镂空的蕾丝质感(铠甲感)。
- **06** 赛博哥特拼贴:黑皮革金属饰物叠黄蓝故障色块。→ `dream-high` 第 6 页(数据马赛克、黄蓝色块)。

### 在 dream-high 里的用法
取色(canvas 量化):01 `#89a6d8` `#b7c9e8`,纸白 `#f7f7f7`;02 `#b7b8cd` `#e5c2c4`,金 `#f0d58a`;03 灰 `#979599`,气球粉 `#c9a3b0`;04 紫 `#6b5a8c`;05 `#e8e4db` `#c7c3bb`;06 黄 `#e8dc4a`,蓝 `#2c46d6`。

| 页 | 参考 | 主题 | 用法 |
|---|---|---|---|
| 1 封面 | 01 | 浅 | 像素花边链,照片映射到像素格 |
| 2 轻 | 03 | 浅 | 气球和折射气泡,鼠标推开 |
| 3 暮 | 02 | 深 | 亮度视差,窗口暖光,抖动 |
| 4 甲 | 05 | 浅 | 亮度求法线,光标点光源 |
| 5 舞 | 04 | 深 | 旋度噪声发丝,色散 |
| 6 噪 | 06 | 浅 | 数据马赛克,黄蓝色块 |
| 7 系 | 全部 | 浅 | 六张参考的像素揭示,占比色条 |
